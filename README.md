# Captioned-Scenes

A small **Code.org Game Lab** mini‑project (JavaScript) that draws a simple outdoor scene using shapes, sprites, and captions.

## What’s in this repo

- `scene.js` — the Game Lab script that builds the scene (background, grass, sun), places two character sprites, and prints short caption text.
- `README.md` — this file.

## How to run (Code.org Game Lab)

1. Open **Code.org → Game Lab**.
2. Create a new project (or open your existing one).
3. Copy/paste the contents of `scene.js` into the Game Lab editor.
4. Add two animations in the **Animation** tab with these exact names:
   - `person1`
   - `person2`
5. Click **Run**.

> Note: `createSprite`, `setAnimation`, and `drawSprites()` are provided by Code.org Game Lab (p5.play style APIs), so this won’t run directly in Node.js or a plain browser JS console.

## What the program does

- Sets a blue background and draws grass + a sun.
- Creates two sprites, assigns animations, positions and scales them.
- Draws two lines of text as captions.

## Customize ideas

- Change the background color and add clouds/trees.
- Replace captions with a short conversation.
- Move sprites or animate them over time.
